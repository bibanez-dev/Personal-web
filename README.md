# Benjamin Ibanez Portfolio

Web app de portfolio personal construida con React + Vite + Tailwind CSS v4.

## Desarrollo local

1. Instalar dependencias:
   `npm install`
2. Ejecutar entorno de desarrollo:
   `npm run dev`

## Build de producción

`npm run build`

El resultado se genera en `dist/`.

## Deploy en Vercel

### Opción recomendada (GitHub + Vercel)

1. Subir el repositorio a GitHub.
2. Importar el proyecto en Vercel.
3. Framework preset: `Vite`.
4. Build command: `npm run build`.
5. Output directory: `dist`.

### Opción por CLI

`npx vercel --prod`
